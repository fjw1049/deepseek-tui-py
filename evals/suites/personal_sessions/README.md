# 个人会话开发集

首批四题从本机 Claude Code 和 Codex 的用户消息节选，按原会话分组。用例描述保留来源、会话文件名去掉扩展名后的 SHA-256 前八位，以及从 1 起算的 JSONL 行号，方便在本机复核。抽样优先选事实可核对、与已有历史题核心判断不同的请求；本批频次不能推算日常使用分布。

| 原会话 | 保留的用户需求 | 为重复评测所作的改编 |
|---|---|---|
| Claude 0005103f | 读代码解释录制给谁用，追问何时保存、跨站能否复用 | 只取保存与回放的追问，使用短小的合成实现，省略原会话最后整理 bug 的要求。 |
| Claude 85fef08b | 核实“只多了浏览器”这个猜测，再切到新版本 | 用两个配置快照和本地活动指针代替远端分支。可测核实差异与切换对象，Git 拉取另测。 |
| Codex c1f58a79 | 用户纠正 interrupted 的 S2 特例，并要求覆盖待续线索以外的情形 | 把上下游缩为一个可运行函数，跨阶段与原因组合验收。首轮现状问题是补写的夹具背景。 |
| Codex 44120cef | 对比十轮完整对话，追问只改客户话、保留客服原话，现场看页面 | 合成十轮对话，追加结构化导出要求便于逐条验收。本题取角色、完整性及页面交付，未重建原会话的整个前端工程。 |

这些是已经阅读并用于设计验收的开发题。日后从同一会话改出的难例沿用同一分组，避免开发集与盲测集重复。会话中的助理旧答案不作为标准答案。

复跑最近两批共十题用 `make eval-personal`。更早的真实会话及完整题库见[数据总账](../../EVAL_RUNBOOK.md)。

首批四题使用众安 deepseek-v4-1-flash，每轮限时 180 秒。[逐题记录](../../../scratch/personal-sessions-pilot/scorecard.md)中前三项任务通过。十轮页面题在第一轮 181 秒时超时，已生成 HTML，但没有机会接收第二条用户纠正。实际共有 58 次工具调用，其中 Shell 33 次；累计输入约 217 万 token（含重复历史）。随后裁判返回无效 JSON，因此评分卡显示 error。应把交付延迟和评分故障分别登记，该次不能用于判断纠正后的改写能力。

[单题复测](../../../scratch/personal-sessions-compare-retry/scorecard.md)将每轮上限调到 360 秒，两轮均完成并通过。对归档文件逐行核对，10 轮客服原话保留、客户话发生改写，原文与改写均可在 HTML 中定位。该次共 67 次工具调用，放宽时间后的通过和原先的超时分别保留。

第二批新增六个独立来源，合计十题。跨标注对账、原生 GUI 测试设计、远程调用诊断、CSS 交互、模型部署名称与评测数据设计。[第二批用例](breadth.yaml)逐条标出本机会话索引及行号。[实跑与耗时复核](../../reports/2026-11-06-personal-breadth.md)包含自动评分和人工改判。
