# 告警与交互优化落实记录

2026-09-13。对应本目录原始审核报告的 F01–F12。本次保留工作区已有的编辑器/视觉改动，仅追加提示与交互修复；未执行真实导入、清库或第三方消息发送。

## 已落实

| 审核项 | 修改后的行为 |
| --- | --- |
| F01 渠道错误崩溃 | 飞书、邮件、企业微信共用错误解码，支持 FastAPI detail 对象、校验数组、字符串和非 JSON，错误不会作为对象送入 React。 |
| F02 错误的已保存状态 | 同一文件的保存按顺序执行；只将实际提交的内容记为 savedContent。保存期间继续输入仍保留未保存标记，不显示误导性的保存成功。切换工作区后的迟到结果不污染当前文件。 |
| F03 设置丢失 | 保存失败或校验失败会保留草稿，返回时提供继续编辑/明确放弃。失败原因和重试按钮直接显示；已保存且未再修改的设置不重复写入。 |
| F04 保存异常无提示 | IPC rejection 和文件服务缺失显示为当前文件的错误，保留编辑内容。 |
| F05 取消却导入 | 改为合并、替换、取消三个独立动作；取消不会发起导入请求。 |
| F06 审批恢复 | 保留提交失败信息及问题答案，提供检查状态；服务端确认同一请求仍 pending 后恢复按钮。补齐提权 pending 查询。不会自动重发不确定的决策。 |
| F07 重复决策 | 提权、演进和用户问题增加 store 防重入，提交状态同步到对应卡片；迟到的响应不会污染已切换的任务。 |
| F08 自动化误报成功 | 按请求统计失败，保留失败任务的旧记录，持续显示不完整状态；全部失败不呈现正常空列表或刷新成功。 |
| F09 MCP 部分失败 | 分别汇总新增、已存在、失败，保留条目错误并支持只重试失败项。写入时重新读取最新配置，避免批量操作覆盖前一项。配置落盘与运行时未生效分别提示。 |
| F10 错误被清除 | 连接错误独立保存；连接探测、置顶成功和回合结束不再无条件清除业务错误。全局提示可跨页面展示，在线业务错误可关闭。此次没有大规模迁移所有业务错误为通知队列。 |
| F11 回合失败变普通文字 | SSE 与历史记录保留错误严重程度；回合级 error 在重载后仍可见。正常状态不升级为错误；完成通知接收成功、失败、停止结果，后台完成轮询也读取结果。 |
| F12 危险确认 | 默认聚焦取消；支持 Tab 圈定、Escape 取消、关闭后焦点恢复。丢弃修改按钮使用明确动作文案，关闭未保存标签也采用危险样式。 |

共同调整：市场与输入框复用 NoticeView，错误不再依赖 5 秒计时消失，支持主动关闭；成功/信息短提示统一为 3 秒。增加动态播报语义、中英文错误文案。提交状态使用“正在提交”，适用于允许和拒绝两种决策。
