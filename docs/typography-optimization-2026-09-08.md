# 主界面与 IDE 字体优化结果

沿用设置 → 外观的现有配置，未增加设置项或改变业务流程。本次参照清晰、克制的桌面字体层级调整，不宣称复刻 Codex 未公开的精确设计参数。

| 项目 | 优化后 |
|---|---|
| 整体小／中／大 | 92%／100%／108%，默认中档不再隐性缩小 |
| UI 字体设置 | 侧栏、输入、聊天、模型选择器统一响应 |
| 阅读字号 | 输入、编辑、用户消息、回答与回答表格统一响应，默认 16px |
| 回答代码 | 等宽；内嵌、结构树、全屏均为阅读字号的 90% |
| 标题 H1–H6 | 跟随阅读字号，两种模式保持相同字号比例 |
| 过程文字 | 普通模式 14px；IDE 13px |
| IDE 文件树／编辑器 | 13px／14px；编辑器行高 22px，代码字体跟随现有主题设置 |
| 终端 | 保留独立的终端字体与字号设置 |
| 微型徽标 | 本次涉及的 8／9px 文字提升至 10px |

验证：外观与会话相关 31 项测试通过；Electron 真实计算样式验证覆盖 72 种字体、缩放、主题、模式、阅读字号组合；排版样本已目视检查。生产构建通过。样本不是运行中所有功能状态的截图验收。

全项目类型检查仍有 27 个错误；使用修改前快照与当前源码对照，错误数量与内容一致，无本次新增错误。未为处理字体而修改无关功能代码。

可重复运行的样式检查位于 `packages/workbench/scripts/check-typography.cjs`，在 workbench 目录使用 `node_modules/.bin/electron scripts/check-typography.cjs`。

提交前另在隔离的暂存快照验证：排除其他未提交功能改动后，29 项相关测试、72 种字体组合检查和生产构建通过。工作区测试数量差异来自未纳入本次提交的会话历史测试改动。
