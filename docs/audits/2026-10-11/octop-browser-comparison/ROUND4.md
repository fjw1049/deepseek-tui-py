## 已实现

1. 顶层与 frame 的受控世界、精确节点派发、局部业务 scope、链接/表单目的变化校验；输入前再次校验控制代次和目标。
2. 完整回放参数替换、结构/长度/URL/按键/selector/条件预检；只读 CSS 语法检查先于接管。输入冻结于内存，不写回步骤或 Skill。
3. action_id 与跨 HTTP/工具/UI receipt、独立未决操作与重复请求复用；人工核对后解除变更阻断。证据失效不抹去已执行事实。
4. 人工输入的文档、标签、viewport、记录键与队列场景校验，晚到 view 淘汰，IME/clipboard 保持原约定，按下状态在失效与结束时释放。人工与模型触发原生弹窗都先返回已派发事实，弹窗回答后收尾。
5. 停止录制 flush 和 transport barrier、失败完整性 gate、共享有限条件与验证范围；350ms 异步字段/标题、隐私、故障和接管回归。
6. 所有输出分支字符预算、scope_ref、describe、长名称和 option_ref、动态分页快照，统一 role/name，隐藏引用名称与 Unicode 截断；截图资产和实际发送尺寸/变换绑定，旧像素坐标拒绝。
7. 能力表、精确任务授权矩阵、有限恢复和耗时；tabs 500ms 缓存、持续输入不逐次落盘，保持 unknown 收据落盘。
8. 显式文件上传、下载落入线程目录并可只读检索、原生 alert/confirm/prompt、多标签 alias 录制回放、8 层祖先 frame 与 OOPIF、open shadow frame owner。上传和 prompt 的录制只留下显式输入参数。

## 验证方式

- 真实 Chrome 只访问 localhost 和临时 profile；包含顶层/shadow/同源/frame/OOPIF、嵌套远程 renderer、祖先 scope 改变、detach、真实录制回放、上传下载与弹窗。
- 实际 Electron 窗口使用临时资料目录和独立运行时端口，挂载生产 BrowserWorkspace；画面点击、中文输入、原生保存确认、目标记录核对通过，未决操作为 0。截图保存于 evidence。
- 真实主模型使用配置的 DeepSeek，任务只包含本地测试数据；确定性执行器任务与自然语言模型任务分开统计。优化前使用第四轮开始时冻结的浏览器源码，同一任务与语言/顺序/动态变体对照；工具 schema 仅适配新描述键和旧 role，不改变基线派发行为。
- 真实视觉 helper 已调用，能识别可见保存提示与是否存在弹窗，并明确单张图不能证明操作历史或持久保存。没有将 helper 事实当作授权。
- 使用临时 imageio-ffmpeg 0.6.0 提供的 FFmpeg v7.1 验证真实 WebM 编码；机器默认 Runtime PATH 没有 FFmpeg，能力表与界面据此标不可用，未把缺失能力计为通过。

## 结果与限制

最终计数、源码 SHA256、日志与安装包校验见 round4-manifest.json；不叠加不同轮次的通过数。

全项目扩展检查一度为 3221 passed、27 failed、3 skipped，其中 2 项工具目录/参数文档已按浏览器/媒体接口更新修复。冻结优化前源码的非浏览器复核仍复现 23 个失败；另一个旧取消测试等待 600s 后失败。此类失败涵盖 checkpoint、摘要提示词、MCP/hooks、subagent/task、token 统计等，未改写这些无关实现，也没有把它们称为通过。完整明细保存在 evidence。

closed shadow 与变换 frame 坐标继续明确受限；动态采集必须先安装，页面行为无法证明时拒绝或请求协助。通用开发预览和自动化 Chrome 是不同会话；传 URL 不传 cookie、登录态或草稿。
