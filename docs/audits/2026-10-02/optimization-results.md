# 前端审核问题修复与优化结果

日期：2026 年 10 月 2 日。基于 `f75e995a` 工作区修改，未创建提交或推送。

本轮逐项核实并处理前次审核中的 F01–F15 功能问题；性能项按复现、渲染数量或基准证据做局部优化。没有为未证实的性能猜测进行大范围重构。原审核覆盖的 31 个功能模块及检查方法保留在 [原审核报告](frontend-review.md) 中；本文件记录其后实际修改及验证结果。

## 功能问题处理

| 编号 / 模块 | 核实后采取的修改 | 验证依据 |
|---|---|---|
| F01 项目切换与编辑草稿 | 按用户选择保留各项目未保存的文本缓冲，切回恢复；已保存文件重新读取 | A/B 项目往返草稿回归测试 |
| F02 编辑器刷新与保存 | 工作区代次、标签实例及刷新序号共同校验；旧读取不能覆盖新保存或较新刷新 | 保存与读取交错、刷新逆序返回测试 |
| F03 看板创建与派发 | 创建会话返回实际成功 ID；失败中止；发送绑定目标 ID；模型选择放在会话加载后 | 创建失败及目标会话不一致测试，既有会话导航测试 |
| F04 自动化通知 | 默认渠道仅初始化未操作的新表单，尊重明确选择的“不通知” | 表单回归测试 |
| F05 一次性自动化编辑 | 从实际接口的 `next_run_at` / `last_run_at` 恢复本地时间；只改说明不重设时间或重新启用已完成任务；后端支持显式更新时间 | 前端表单及后端管理器测试 |
| F06 长对话生成 | 删除进入生成状态时强制展开全部历史的逻辑 | 40 轮历史在开始生成前后均只挂载 18 轮 |
| F07 跳转历史消息 | 先挂载目标所在历史，再完成定位；查询限定当前消息容器 | 隐藏历史定位测试 |
| F08 终端切换 | 输出订阅移到会话层；面板卸载时仍接收输出和退出事件，重开后回放 | 无面板监听时输出、退出状态、缓冲上限测试 |
| F09 编辑器关闭加载标签 | 读取完成前校验请求和标签是否仍有效；关闭或重新打开不会接收旧结果 | 关闭加载标签回归测试 |
| F10 自动化运行记录 | 按选择与请求序号丢弃旧结果，避免 A 的慢响应覆盖 B | A 慢、B 快的组件交错测试 |
| F11 运行任务索引 | 后端先按活动状态/指定 ID 筛选，再排序截断；前端请求活动任务或所需 ID | 超过 100 条新任务时仍发现旧运行任务；接口合同测试 |
| F12 大段粘贴附件 | 捕获目标上下文，异步完成后核对；函数式追加保留并发附件，处理期间避免提前发送 | 乱序完成两次粘贴、切换目标测试 |
| F13 文件预览 | 保存/刷新更新预览版本，图片、HTML、PDF URL 随版本更新 | PDF URL 刷新回归及相关预览测试 |
| F14 模型列表与密钥 | 获取模型列表使用临时传入密钥，不再提前写入设置 | 获取列表不调用设置保存的断言 |
| F15 邮件配置写入 | 带原始内容进行比较后写入，串行处理应用内写请求；冲突明确提示重新打开设置 | 真实临时文件的过期写入、并发写入测试 |

F05 的修复以真实后端字段为准：原记录没有 `run_at` 字段；`run_at` 用于显式更新请求。

## 性能项处理

| 编号 | 实际处理与边界 |
|---|---|
| R01 Git 变更加载 | 同一次请求共享未跟踪文件补丁结果，最多 4 个读取并行；保持返回补丁内容不变。未重写为按文件懒取整个接口。 |
| R02 流式渲染 | 分离分屏消息列表与输入框订阅，稳定回调。测试中一次助手流式增量使输入框额外渲染次数为 0。未凭推测重构所有 Workbench 订阅。 |
| R03 会话缓存 | 保留最多 8 个可淘汰闲置会话；可见、运行中、有队列及无法保存草稿的会话受到保护。20 个闲置候选含 1 个运行会话的测试，最终保留 8 个闲置和 1 个运行会话。 |
| R04 初始包体 | 设置、市场、看板、自动化和渠道页面按需加载；等待时显示加载状态。Workbench 构建块由 2595.39 kB 降至1901.80 kB，减少约 26.7%。编辑器独立块仍约 7349.55 kB，未声称解决所有包体问题或测得启动提速。 |
| R05 大文件渲染 | 差异预览限制 2000 行 / 200,000 字符，超大完整文件回退实际变更补丁并提示；复制仍取完整补丁。超过高亮阈值使用纯文本。表格在既有最多 500 行 / 50 列范围内每页 50 行，最大同时渲染 2500 个数据单元格。 |
| R06 后台浏览器标签 | 未修改。未取得实际卡顿证据，自动休眠可能破坏表单和页面状态；保留现有行为，待真实浏览器性能记录后决定。 |
| R07 轮询与请求叠加 | 任务、连接器、完成状态和待处理输入请求增加进行中保护；自动化运行历史按最多 4 路请求加载，过期批次停止继续调度。 |

### Git 基准

同一临时仓库：200 个未跟踪文件，每个 20 行。直接使用基线与修改后 Git 服务交替运行 3 次，每次断言结果完全相等。以下为服务调用耗时，不能外推为整机交互速度。

| 轮次 | 修改前（ms） | 修改后（ms） |
|---|---:|---:|
| 1 | 764.56 | 230.13 |
| 2 | 738.34 | 210.00 |
| 3 | 740.75 | 212.62 |
| 中位数 | **740.75** | **212.62** |

该场景中位耗时减少约 **71.3%**。表格分页测试覆盖翻至末页；超大差异测试确认第 9000 行附近的变更仍展示，挂载行数小于 20。

## 检查结果

- 前端完整测试：206 个测试文件，**1261 项通过**，无跳过失败来获得通过。
- 相关后端回归：**31 项通过**，覆盖任务过滤、自动化管理及对应接口合同。
- TypeScript 类型检查通过。
- ESLint 无错误，仍有 **9 条既有警告**。排除遗留依赖垃圾目录，没有删除该目录或批量修改第三方文件。
- Electron 主进程、预加载与渲染端生产构建通过。
- `git diff --check` 通过。

Q01 中的类型不匹配、测试环境存储冲突、过期界面断言及时间不稳定测试已逐项修正。保留了测试的业务断言，补充了竞态和错误路径测试。测试运行仍可能输出 Node 的 localStorage 路径提示，不影响测试结果。

## 使用范围与未验证部分

1. 项目草稿保留在本次应用运行的内存中，支持切换项目再切回；**不包含退出应用或崩溃后的恢复**。恢复未保存标签时使用主编辑区，不恢复原分屏排列。
2. 终端每会话保留最近约 1,048,576 个 UTF-16 字符用于重开回放；不是无限日志存档。
3. 大差异和表格采用有提示的有限预览。按需加载的低频页面首次进入可能出现短暂加载状态。
4. 邮件配置冲突时拒绝覆盖并提示重新打开，未实现配置自动合并；该保护不是跨所有外部程序的文件锁。
5. 本轮没有真实 Electron 全流程点击、真实模型流式端到端测试，未采集 FPS、输入延迟、CPU 或长时间内存曲线。不能仅凭单元测试和构建宣称所有设备都已达到“丝滑”。真实账户、语音硬件、渠道与外部服务的端到端验收仍按原审核方案执行。
